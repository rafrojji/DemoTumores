# Demo flujo hospitalario - tumores cerebrales

Este demo presenta cómo podría usarse el modelo en un sistema hospitalario.

## Flujo incluido

1. Imagen médica
2. Extracción de características
3. Modelo IA
4. Clasificación
5. Médico revisa
6. Decisión clínica

## Resultados reales incorporados

- Accuracy: 0.9529
- Precision: 0.9956
- Recall: 0.9534
- F1-score: 0.9740
- AUC-ROC: 0.978368
- Umbral de alerta: 0.212
- Umbral alto: 0.70

## GitHub Pages

1. Crear un repositorio.
2. Subir estos archivos a la raíz.
3. Ir a `Settings > Pages`.
4. Elegir `Deploy from a branch`.
5. Seleccionar `main` y `/root`.
6. Guardar.
