# Video interactivo por pasos

Este demo convierte el video en una experiencia interactiva.

## Cómo funciona

- El video se reproduce.
- Al terminar cada paso, se pausa automáticamente.
- Aparece una explicación del paso.
- El expositor presiona **Continuar al siguiente paso**.
