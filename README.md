# Demo IA - Clasificación de Tumores Cerebrales

Este repositorio contiene un demo web estático para presentar el proyecto final del Grupo 4.

## ¿Qué muestra?

- Descripción ejecutiva del problema.
- Métricas del modelo de Regresión Logística.
- Matriz de confusión con umbral estándar.
- Matriz de confusión con umbral ajustado.
- Simulador de predicción usando las variables del dataset.

## Archivos

- `index.html`: página principal.
- `styles.css`: estilos visuales.
- `app.js`: lógica del simulador y parámetros del modelo.
- `.nojekyll`: evita procesamiento innecesario con Jekyll en GitHub Pages.

## Cómo publicarlo en GitHub Pages

1. Crear un repositorio en GitHub, por ejemplo: `demo-tumores-ia`.
2. Subir estos archivos en la raíz del repositorio.
3. Ir a `Settings`.
4. Entrar a `Pages`.
5. En `Build and deployment`, seleccionar:
   - Source: `Deploy from a branch`
   - Branch: `main`
   - Folder: `/root`
6. Guardar.
7. Esperar a que GitHub genere el enlace público.
