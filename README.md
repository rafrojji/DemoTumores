# NeuroScan Grupo 4 - Demo fusionado

Demo web estático para GitHub Pages, construido con los resultados reales del notebook `Grupo4Tumores`.

## Qué incluye

- Diseño médico/IA con efecto visual 3D.
- Simulador interactivo usando los coeficientes reales de la Regresión Logística.
- Métricas reales del notebook:
  - Imágenes procesadas: 1273
  - Variables predictoras: 16
  - Accuracy: 0.9529
  - Precision: 0.9956
  - Recall: 0.9534
  - F1-score: 0.9740
  - AUC-ROC: 0.978368
- Matriz de confusión con umbral 0.50.
- Matriz de confusión con umbral ajustado 0.212.
- Sistema de tres zonas del notebook.
- Sección CRISP-DM para exposición.

## Archivos

- `index.html`
- `styles.css`
- `app.js`
- `README.md`
- `.nojekyll`

## Cómo publicarlo

1. Crear un repositorio en GitHub.
2. Subir estos archivos a la raíz del repositorio.
3. Ir a `Settings > Pages`.
4. Seleccionar `Deploy from a branch`.
5. Escoger branch `main` y folder `/root`.
6. Guardar y abrir el enlace publicado por GitHub Pages.
