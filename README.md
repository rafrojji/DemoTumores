# Demo iterativo - flujo clínico cerebral

Este demo funciona en una sola página y avanza paso a paso con clics.

## Flujo
1. Imagen médica
2. Extracción de características
3. Modelo de clasificación
4. Clasificación por zona
5. Revisión médica
6. Reporte final

## Archivos
- index.html
- styles.css
- app.js
- README.md
- .nojekyll

## Uso
1. Subir estos archivos a GitHub.
2. Activar GitHub Pages.
3. Abrir `index.html`.
4. Ir dando clic en **Siguiente** para avanzar en el flujo.

## Notas
- Incluye un caso ejemplo ya precargado.
- Usa resultados reales del proyecto.
- El reporte final puede imprimirse desde el navegador.
