Ejemplo completo

Caso demo listo para exponer

Esta página ejecuta un caso completo sin necesidad de subir archivos. Sirve para enseñar al profesor cómo el sistema conecta imagen, extracción de variables, modelo IA, clasificación, revisión médica y reporte final.

El caso demo usa una imagen sintética generada en el navegador. La extracción calcula variables desde el canvas y luego las envía al modelo de Regresión Logística entrenado con los resultados reales del proyecto.

Qué verá el jurado

  1. Imagen médica demo generada automáticamente.
  2. Extracción de 16 variables predictoras.
  3. Probabilidad calculada por Regresión Logística.
  4. Zona negativa, zona de duda o zona alta.
  5. Revisión simulada del médico.
  6. Reporte final imprimible.
