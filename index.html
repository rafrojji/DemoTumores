Propuesta demo del sistema según el flujo del hospital

Este demo muestra cómo un médico podría usar el modelo dentro de un sistema institucional: desde la recepción de la imagen hasta la decisión clínica final.

En esta propuesta, la IA no reemplaza al médico. El modelo apoya la priorización y la revisión clínica usando las variables numéricas extraídas de la imagen.

En un flujo real, el hospital recibe una resonancia o imagen cerebral del paciente. El sistema no emite un diagnóstico directo sobre la imagen: primero debe transformarla en información cuantificable.

Mensaje para presentar: el modelo no trabaja directamente sobre la imagen visible, sino sobre las variables numéricas ya extraídas del estudio.

La decisión clínica nunca la toma la IA sola. El médico puede confirmar, descartar o solicitar estudios adicionales según el contexto del paciente.
